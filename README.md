## 🐾 关于游戏

欢迎来到 **猫猫盘串铺**，一款像素风格的文玩盘串放置游戏。

在小猫们的陪伴下，盘动手中的菩提手串，积攒 **禅意**，解锁更珍稀的珠串，装点你的猫猫小屋，达成灵修心愿。

---

## 🎮 玩法

| 操作 | 说明 |
|------|------|
| 🖱️ **盘串** | 点击中央的菩提台，每次点击获得禅意，手串在指尖旋转 |
| 🐱 **猫缘** | 招募猫猫伙伴，它们会持续为你产出 **猫息**（被动收入） |
| 📿 **珠阶** | 积攒足够禅意后解锁更高级的手串 — 菩提根 → 猴头 → 星月菩提 → 小金刚 |
| 🪴 **装饰** | 购买猫爬架、猫窝、抓抓柱等装饰，提升各项产出倍率 |
| ⭐ **心愿** | 完成阶段性目标，获得 **福爪** 永久加成 |

## 🛠️ 技术栈

纯原生前端三件套，零依赖，打开即玩：

- **HTML5** — 语义化结构，无障碍支持
- **CSS3** — 像素风视觉系统，CSS 精灵动画，响应式布局
- **Vanilla JS** — 离线收益计算，LocalStorage 自动存档

---

## 🚀 快速开始

```bash
# 任意静态服务器即可
npx serve .
# 或
python -m http.server 8080
```

然后打开 `http://localhost:8080`
